# AI Weekly Report

This repository records weekly AI-assisted work progress, reusable workflows, and safe management-facing summaries.

## Purpose

- Record weekly AI usage in a format that leaders can review.
- Keep reusable work notes, templates, and process improvements.
- Support GitHub-based weekly progress scanning.

## Repository Rules

- Do not upload passwords, tokens, cookies, private keys, or `.env` files.
- Do not upload raw business data, customer data, student data, supplier data, contracts, quotations, orders, revenue, costs, or private exports.
- Do not upload unredacted screenshots, chat records, logs, BI exports, CRM exports, or backend system exports.
- Use fake data, desensitized examples, or public data only.

## Structure

```text
docs/
  weekly/
    2026-05-19-weekly-ai-report.md
examples/
scripts/
config.example.yaml
.env.example
.gitignore
```

## Weekly Workflow

1. Create or update this week's report under `docs/weekly/`.
2. Check that no sensitive information is included.
3. Commit with a clear message, for example:

```text
docs: add weekly AI usage report for 2026-05-19
```

4. Push to GitHub.
5. Create a Pull Request if the team requires review.
