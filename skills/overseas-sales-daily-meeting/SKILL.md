# Overseas Sales Daily Meeting

Use this skill for the recurring overseas daily sales meeting package where multiple modules, formatting rules, and summary write-backs must stay aligned.

## Workflow

1. Read `references/sop.md`.
2. If the user asks for a new daily doc, create it from the current template first.
3. Export SmartBI data module by module with the date rules from the SOP.
4. Update only the intended cells or ranges; preserve formulas and formatting.
5. Generate summary issues from the data written back into the document.

## Resource

- `references/sop.md`: current operational notes, module map, report paths, and validation rules
