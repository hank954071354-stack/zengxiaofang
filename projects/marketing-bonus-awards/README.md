# Marketing Bonus Awards

This project folder keeps reusable script logic for the recurring sales marketing bonus workbook flow.

## Included

- `scripts/calc_current.py`: historical calculation script snapshot for the 2.2 销售营销加码赠课 workflow

## Not included

- source SmartBI exports
- template `.xls` workbooks
- generated final payout workbooks

Those private Excel inputs stay in the local work directory. This repo keeps the reusable logic only.
